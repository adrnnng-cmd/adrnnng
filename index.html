Approach

How the work is done

01

Rules, not opinions

Indicators like RSI or MACD invite you to see what you want to see. DeMark's TD Sequential is a strict count: nine closes for a Setup, thirteen for a Countdown. Objective rules can be tested.

02

Verified in code

Every strategy here started as a Python or Pine Script model. The backtester is cross-checked against an independent implementation, and its metrics are tested against hand-worked examples.

03

Shown in public

Real data, published sources, no cherry-picked screenshots. Anyone can rerun a backtest, change a parameter and share the link.
